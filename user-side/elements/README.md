# @hmpt/elements

The driving adapters: port-bound custom elements — `hmpt-today-card`, `hmpt-greeting`,
`hmpt-streak-summary`, `hmpt-history-calendar`, `hmpt-achievement-list`, `hmpt-bookshelf`, `hmpt-profile-form`,
`hmpt-range-form`, `hmpt-reminder-form`, `hmpt-celebration` — plus `readingContexts`, the typed
context keys they request, and `defineReadingElements()`.
